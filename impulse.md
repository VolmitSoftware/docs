Impulse turns dispensers into machines for harvesting, mob grinding, collection, shooting, breaking, and placement. Machines use their nine inventory slots and have an owner, level, pause state, and redstone mode.

| Requirement | Value |
| --- | --- |
| Minecraft | 26.1 through 26.3 |
| Java | 25 or newer |
| Server targets | Spigot, Paper, Purpur, Leaf, Folia, Canvas |
| Main command | `/impulse` or `/imp` |
| Configuration | `plugins/Impulse/config.toml` |
