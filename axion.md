Axion runs mining, harvesting, item collection, and optional combat from storage controllers. Signs steer each machine's route.

| | |
| --- | --- |
| Server software | Spigot, Paper, Purpur, Leaf, Folia, Canvas |
| Minecraft | 26.1 through 26.3, including patch releases |
| Java | 25 or newer |
| Main command | `/axion` (`/ax`) |
| Config file | `plugins/Axion/config.toml` |
| Controller | Barrel with 27 slots; dropper or dispenser with 9 slots |
