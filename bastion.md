Bastion protects land claims that cover the full world height. Players claim chunks, rectangles or circles, decide who can do what through inventory menus, and rent or sell child plots inside their land.

| | |
|---|---|
| Server software | Spigot, Paper, Purpur, Leaf, Folia, Canvas; some features are unavailable on region-threaded servers |
| Minecraft | 26.1 through 26.3 |
| Java | 25 or newer |
| Main command | `/bastion` (`/bn`) |
| Configuration | `plugins/Bastion/config.toml` |
