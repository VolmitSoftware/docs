Temper repairs equipment using quoted XP, money, material, or kit costs. Players can repair one item or a batch through commands and owned anvil stations.

| | |
|---|---|
| Server software | Spigot, Paper, Purpur, Leaf, Folia, Canvas |
| Minecraft | 26.1 through 26.3 |
| Java | 25 or newer |
| Main command | `/temper` (`/tem`) |
| Configuration | `plugins/Temper/config.toml` |
| Money payments | Optional Vault economy provider |
