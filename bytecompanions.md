ByteCompanions gives each player a collection of companions built from vanilla items and heads, with saved outfits, particles, and optional attribute, buff, potion, progression, and booster features. Operators edit companion definitions in game with Companion Studio and change settings with the shared configuration editor or by saving the TOML files.

| | |
|---|---|
| Server software | Spigot, Paper, Purpur, Leaf, Folia, and Canvas |
| Minecraft | 26.1 through 26.3, including patch releases |
| Java | 25 or newer |
| Main command | `/bytecompanions` (`/companions`, `/bc`) |
| Config file | `plugins/ByteCompanions/config.toml` |
| Starter companions | `bee`, `copper`, `lantern`, `mushroom`, `myself`, `rainbow`, `scout`, `warrior` |
