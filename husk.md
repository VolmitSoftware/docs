Husk is a Java 25 project template for Spigot, Paper, Folia, Fabric, Forge, and NeoForge. It builds one Bukkit-family jar and a separate mod jar for each loader and Minecraft version. The included runtime demonstrates startup, shutdown, typed configuration, a status command, and the Volmit startup splash using VolmLib.
