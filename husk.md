Husk is a project template built with JDK 25 for Spigot, Paper, Folia, Fabric, Forge, and NeoForge. It builds one Bukkit-family jar and a separate mod jar for each loader and Minecraft version, with Forge and NeoForge sharing the 1.20.1 jar. Supported Minecraft releases are 1.20.1, 1.21.1, 26.1.2, 26.2, and 26.3. The included runtime demonstrates startup, shutdown, typed configuration, a status command, and the Volmit startup splash using VolmLib.
