Sigil provides signed physical reward vouchers, inventory editors and persistent redemption records. Players preview and redeem items; operators configure rewards and inspect interrupted deliveries.

| | |
|---|---|
| Minecraft | 26.1 through 26.3 |
| Java | Released 25 or newer |
| Server targets | Spigot, Paper, Purpur, Leaf, Folia and Canvas |
| Main command | `/sigil` (`/sg`, `/vouchers`) |
| Configuration | `plugins/Sigil/config.toml` and `vouchers/<id>.toml` |
