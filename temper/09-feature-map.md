Temper combines quoted equipment repairs with configurable costs, kits, and owned stations. Each workflow retains equipment in the player’s inventory until confirmation.

| Workflow | Available controls |
|---|---|
| Single and bulk repairs | Hand, numbered slot, inventory, armor, or all equipment; partial restoration |
| Payment | XP points, Vault money, plain materials, or an offhand repair kit |
| Pricing | Formula limits, material profiles, and deterministic permission discounts/cooldowns |
| Stations | Owner/public access, individual hologram/preview/effect toggles, protection, and anvil interaction modes |
| Presentation | Optional Gloss station labels and floating item previews; configurable particles and sounds |
| Configuration | Typed TOML, automatic reload, shared settings editor, and collection editors |
| Languages | 18 catalogs, personal selection, message editor, and English fallback |
| Payment records | Persistent unresolved records and bounded completed-history archives |
| Administration | Director help, status, version commands, local or uploaded diagnostic reports |
