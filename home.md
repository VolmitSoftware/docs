Build custom worlds, extend gameplay, tune performance, and create polished
server experiences with Volmit Software's Minecraft plugins.

Choose a plugin to get started. Its landing page includes requirements and
direct paths to installation, configuration, commands, and developer APIs.

## Server plugins

- [**Iris** *Create custom dimensions, biomes, caves, structures, and terrain from JSON packs.*](/iris)
- [**Adapt** *Add passive skills, abilities, mutations, and player progression.*](/adapt)
- [**React** *Monitor server health, investigate lag, and improve performance.*](/react)
- [**Wormholes** *Connect locations and servers with rendered portals and dimensional doors.*](/wormholes)
- [**Gloss** *Build holograms, menus, panels, scoreboards, and other live displays.*](/gloss)
- [**HiddenOre** *Control mining rewards while keeping valuable blocks hidden from x-ray.*](/hiddenore)
