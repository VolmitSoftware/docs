Inscribe moves enchantments between equipment and books through an inventory menu with a confirmed price. Equipment and books stay in the player's inventory until the transfer commits.

| Area | Available controls |
| --- | --- |
| Transfers | Selective extraction and application, confirmation, anvil-style level merging and repair cost, allowed material lists, vanilla behavior when no transfer is possible |
| Pricing | Experience points or Vault money, fixed and per-level prices, per-enchantment policies |
| Settings | Typed TOML in named sections, validation, hot reload with operator notices, translated in-game editor |
| Languages | Built-in English, 17 repository translations installed on first use, updates that keep local edits, custom files with `[meta]` names and bases, personal choices, in-game message editing |
| Commands | Permission-filtered help, `/ins` alias, status menu, debug commands, shared suite commands |
| Diagnostics | Local reports with optional uploads, including settings, open menus, and language and integration state |
| Releases | Shared GitHub notices and release links, with an on/off setting |
| Metrics | bStats service `34581`, local toggle, shared opt-out |
