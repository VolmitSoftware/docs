Brimstone adds custom TNT that players launch by left-clicking the air. Operators set each launcher's effect, recipe, fuel cost, and explosion in `brimstone.toml` or an in-game editor.

| | |
|---|---|
| Server software | Spigot, Paper, Purpur, Leaf, Folia, and Canvas |
| Minecraft | 26.1 through 26.3, including patch releases |
| Java | 25 or newer |
| Main command | `/brimstone` (`/brim`) |
| Config file | `plugins/Brimstone/brimstone.toml` |
| Default launchers | `notch`, `creeper`, `firework`, `love`, `dj`, `rainbow`, `water`, `impact`, `cluster`, `bouncy`, `frost`, `smoke` |
| Optional plugins | WorldGuard, and any claim or protection plugin that controls block breaking |
