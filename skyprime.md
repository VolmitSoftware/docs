SkyPrime provides separate island worlds with teams, visitor protection and configurable progression. Players choose starter terrain, expand their island and unlock optional Nether and End worlds. Commands and inventory menus use cyan and white.

| | |
|---|---|
| Server software | Spigot and Paper, Minecraft 26.1 through 26.3; stock Folia is unsupported |
| Java | 25 |
| Main command | `/skyprime` (`/sky`, `/is`, `/island`) |
| Config file | `plugins/SkyPrime/config.toml` |
| PlaceholderAPI | Optional |
