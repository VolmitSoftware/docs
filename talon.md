Talon adds ability books for tool switching, mining groups of blocks, and collecting drops. Each of its five abilities has three levels.

| | |
|---|---|
| Platform targets | Spigot, Paper, Purpur, Leaf, Folia, Canvas |
| Minecraft | 26.1 through 26.3, including patch releases |
| Java | 25 or newer |
| Main command | `/talon` (`/tl`) |
| Config file | `plugins/Talon/config.toml` |
| Abilities | Multi Tool, Remote Loot, Blast, Vein Miner, Excavation |
