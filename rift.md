Rift creates, imports, loads, unloads, quarantines, restores, and teleports between server worlds. Deleting a world is a confirmed quarantine you can undo.

| | |
|---|---|
| Version | 2.0.1-26.x |
| Server software | Paper 26.x; Folia with lifecycle limits |
| Java | 25 or newer |
| Main command | `/rift` (`/rft`) |
| Config file | `plugins/Rift/config.toml` |
| Folia | Partial. World create, load, and unload are disabled |
