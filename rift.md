Rift creates, imports, loads, unloads, quarantines, restores, and teleports between server worlds. Deletion uses a confirmed quarantine-and-restore flow.

| | |
|---|---|
| Version | 2.0.0-1.20.1-26.2 |
| Servers | Spigot 1.20.1 through 26.2 |
| Server Java | The Java version required by the selected server, at least Java 17 |
| Command | `/rift` (`/rft`) |
| Storage | TOML configuration, profiles, and quarantine manifests |
| Folia | Loads safely; dynamic world create/load/unload operations are gated |
