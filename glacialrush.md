GlacialRush runs territory-conquest rounds between Omni, Enigma, and Cryptic. Players join balanced factions, capture linked objectives, and earn progression that unlocks loadouts, equipment upgrades, and runes.

## Requirements

| Requirement | Value |
|---|---|
| Minecraft | 26.1 through 26.3 |
| Server | Paper or Folia |
| Java | 25 |
| Command | `/grush` or `/glacialrush` |
| Configuration | `plugins/GlacialRush/config.toml` and `plugins/GlacialRush/arenas/<arena>.toml` |
