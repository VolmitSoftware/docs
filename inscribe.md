Inscribe moves selected enchantments from equipment into a book and applies enchanted books to equipment. Players right-click with a book in their inventory, choose enchantments in a menu, and confirm the price.

| | |
|---|---|
| Server software | Spigot, Paper, Folia |
| Minecraft | 26.1 through 26.3 |
| Java | 25 or newer |
| Main command | `/inscribe` (`/ins`) |
| Configuration | `plugins/Inscribe/config.toml` |
| Money payments | Optional Vault economy provider |
