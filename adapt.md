Adapt adds 24 skills. Actions award skill XP. Levels award knowledge, which buys adaptations. Each learned adaptation takes one slot of a shared ability-power budget.

| | |
|---|---|
| Server | Paper, Purpur, Folia, or Spigot, or Fabric, Forge, or NeoForge |
| Command | `/adapt` |
| Menu | Side-click the activator block. Default: bookshelf |
| Config | `plugins/Adapt/`, or `config/adapt/` on mod servers |
