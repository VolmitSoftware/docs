![Animus](/home-assets/animus.png =96x){.align-center}

Animus manages NPCs. Each NPC is a JSON definition file that you can edit by hand, from commands, or in the web editor. NPCs are packet-only and shown separately to each viewer. An NPC is either spawned, and shown to players, or dormant: saved but not shown. Behaviors, routes, combat, shops, chest GUIs, and builds are all set in JSON.

| | |
|---|---|
| Minecraft | 26.1.2, 26.2, and 26.3 |
| Server software | Paper, Spigot, Folia; Fabric, NeoForge, and Forge as an experimental server-side mod |
| Java | 25 or newer |
| Main command | `/animus` |
| Config file | `plugins/Animus/config.toml` |
| Editor | [animus-editor.web.app](https://animus-editor.web.app) |
