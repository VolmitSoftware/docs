Talon stores abilities on individual tools. Books add or upgrade an ability while preserving the tool's existing metadata.

## First use

1. Open `/talon books` and select a book to see its recipe, effect, and compatible tools.
2. Craft the book. Pick it up with the cursor and left-click a compatible tool in your inventory to apply it.
3. Hold the tool and run `/talon inspect`. Use `/talon mode` to choose one of its mining abilities.

By default, abilities work in survival mode and pause while sneaking. `/talon toggle` changes the held tool's enabled state. Multi Tool and Remote Loot can work alongside the selected mining mode.

## Common commands

| Command | Purpose |
|---|---|
| `/talon books` | Browse books and recipes |
| `/talon inspect` | Read the held tool's abilities and state |
| `/talon mode` | Cycle available mining modes and single-block mining |
| `/talon loot inventory` | Collect drops in your inventory |
| `/talon config` | Edit server settings with `talon.config` |
